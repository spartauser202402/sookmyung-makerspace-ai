## 2. 슬라이싱 단계별 절차

### Step 1 — 파일 불러오기
1. 3DWOX Desktop을 실행합니다.
2. 상단 메뉴 **파일 > 불러오기** 또는 화면에 STL/OBJ 파일을 드래그합니다.
3. 모델이 출력판(베드) 위에 올라오는지 확인합니다.

### Step 2 — 출력 설정
1. 왼쪽 패널에서 **필라멘트 종류를 'PLA'** 로 선택합니다. *(PLA 고정 — 다른 소재 불가)*
2. 레이어 높이를 선택합니다:
   - 빠른 출력: **0.2 mm**
   - 일반: **0.15 mm**
   - 정밀: **0.1 mm**
3. 인필(채움) 밀도를 설정합니다:
   - 프로토타입/테스트: 15~20%
   - 일반 목적: 20~30%
   - 기능성 부품: 40~50%
4. 오버행(돌출부)이 있는 경우 **서포트를 활성화** 합니다.
5. 바닥 접착 문제가 우려되면 **브림(Brim)을 추가** 합니다.

### Step 3 — 슬라이싱 & 저장
1. **슬라이싱** 버튼을 클릭합니다 (처리 시간: 수십 초~수 분).
2. 예상 출력 시간과 필라멘트 사용량을 확인합니다.
3. **저장** 버튼으로 `.gcode` 파일을 PC에 저장합니다.
4. 파일명을 이용수칙 형식으로 변경합니다:
   ```
   형식: 출력날짜_시간_이름.gcode
   예시: 20261130_13_강채린.gcode
   ```

### Step 4 — 파일 전송
5. `makerspace@sookmyung.ac.kr` 로 `.gcode` 파일을 첨부하여 이메일 전송합니다.

## 3. 출력 가능 사양 [확인 필요]

| 항목 | 사양 |
|---|---|
| 최대 출력 크기 | 약 210 × 200 × 195 mm [확인 필요] |
| 노즐 직경 | 0.4 mm [확인 필요] |
| 최소 레이어 높이 | 0.05 mm [확인 필요] |
| 필라멘트 지름 | 1.75 mm [확인 필요] |

---

## 4. 주의사항

- **당일 취소 불가** — 예약 전 일정을 반드시 확인하세요.
- 예약 시간 10분 이내에 도착해야 합니다.
- 출력 중 자리를 비울 수 있으나, 출력 완료 후 즉시 모델을 회수하세요.
- 출력 실패 시 메이커스페이스 담당자에게 즉시 문의하세요.

## 5. 자주 하는 실수

| 실수 | 올바른 방법 |
|---|---|
| STL 파일을 그대로 메일로 보냄 | 3DWOX Desktop에서 .gcode로 변환 후 전송 |
| 파일명 형식 미준수 | 출력날짜_시간_이름.gcode 형식 준수 |
| ABS/PETG 슬라이싱 설정 사용 | 반드시 PLA 선택 |
| 슬라이싱 없이 STL 저장 | 슬라이싱 버튼 클릭 후 .gcode 저장 |
