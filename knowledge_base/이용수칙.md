# 숙명 메이커스페이스 이용수칙

> 출처: 중앙도서관 숙명창작소 공지사항 | 최종 수정일: 2026-11

## 기본 원칙
- 반드시 이용수칙을 숙지한 후 3D 프린터 예약을 진행하십시오.
- 이용수칙 위반 시 강제 취소될 수 있습니다.

## 3. 출력 파일 제출 방법

예약 당일, 반드시 아래 절차대로 파일을 전송해야 합니다.

```
수신 이메일: makerspace@sookmyung.ac.kr
파일 형식: .gcode (3DWOX1 슬라이서로 변환 필수)
파일명 규칙: 출력날짜_시간_이름.gcode
최대 출력 시간: 12시간 (초과 시 출력 불가, 관리자 취소 가능)
```

**파일명 예시**
- 2026년 11월 30일 13시, 강채린: `20261130_13_강채린.gcode`
- 2026년 12월 01일 11시, 김지수: `20261201_11_김지수.gcode`

> ⚠ STL, OBJ, 3MF 등 다른 형식의 파일은 접수하지 않습니다.
> 반드시 **3DWOX1 슬라이서**로 변환한 `.gcode` 파일만 전송하세요.

**메일 작성 시 주의사항**
- 메일은 공손한 표현으로 작성해야 합니다.
- 메일 제목: 예약 날짜, 시간, 이름을 포함하여 명확히 작성하세요.
- 첨부 파일명이 규칙(출력날짜_시간_이름.gcode)에 맞는지 반드시 확인하세요.

## 4. 출력 당일 방문 절차

출력 당일에는 아래 항목을 반드시 지참하여 숙명창작소를 방문하세요.

| 지참 항목 | 비고 |
|---|---|
| 학생증 (QR코드 또는 카드) | 본인 확인용 |
| 3DWOX1 정품 필라멘트 | 개인 구매 필요 |
| 스마트칩 | 필라멘트와 함께 제공 |

> ⚠ **대리 신청·출력·수령은 불가합니다.** 반드시 본인이 직접 방문해야 합니다.

출력 시작 전, 본인의 파일이 맞는지 직접 확인한 후 출력을 시작하세요.

---

## 5. 출력 완료 후 수령 방법

- 출력이 완료되면 **이메일(또는 문자)로 완료 알림**이 발송됩니다.
- **알림 수신 후 숙명창작소를 방문**하여 출력물을 수령하세요.
- 출력 완료 메시지 발송 후 **48시간 이내에 수령하지 않으면 재료와 출력물이 폐기**됩니다.
- 문자/이메일을 반드시 확인하고, 늦지 않게 방문하세요.

---

## 6. 출력 품질 체크리스트 (파일 제출 전 필수 확인)

파일 제출 전 슬라이서에서 아래 항목을 반드시 확인하세요.

- [ ] **레프트(Raft)** 설정 확인 — 필요 여부 판단
- [ ] **서포트(Support)** 설정 확인 — 오버행 45도 이상 시 필수
- [ ] 출력 예상 시간이 **12시간 이하**인지 확인
- [ ] 노후화된 필라멘트 사용 금지 (관리자 제공 필라멘트만 사용)
- [ ] 무리한 출력 속도 조정 금지

> ⚠ 모델링 오류, 출력 설정 실수, 파일명 오류, 레프트/서포트 누락 등 **본인 과실로 인한 문제는 메이커스페이스에서 책임지지 않습니다.**

## 7. 시설 이용 주의사항

- **음식물·음료(물 포함) 반입 금지** — 장비 보호를 위해 엄격히 금지됩니다.
- **장비 파손·사고 시 배상 의무** — 고의 또는 과실로 장비가 파손되거나 사고 발생 시 즉시 원상복구하거나 손해를 배상해야 합니다.
- **개인 소지품·출력물 분실 책임** — 개인 소지품 및 출력물 분실에 대한 책임은 이용자 본인에게 있습니다. 개인 사유로 소지품 보관은 불가합니다.
- 중앙도서관 「자료 및 시설 이용지침」을 준수해야 하며, 위반 시 도서관 이용이 중지될 수 있습니다.
- **필라멘트 대여·교환, 추가 출력 등 원칙 외 서비스는 제공하지 않습니다.**

## 8. 자주 묻는 질문 (FAQ)

**Q. STL 파일을 그대로 보내도 되나요?**
A. 안 됩니다. 반드시 3DWOX1 슬라이서로 `.gcode`로 변환 후 제출해야 합니다.

**Q. 다른 필라멘트(ABS, PETG 등)를 사용할 수 있나요?**
A. 현재 메이커스페이스는 PLA 필라멘트만 제공합니다. 다른 소재는 이용 불가합니다.

**Q. 예약 후 취소하고 싶어요.**
A. 당일 취소는 불가합니다. 예약 전 일정을 충분히 확인하세요.

**Q. 예약이 꽉 찼어요.**
A. AI 코파일럿에게 대기열 등록을 요청하면 취소 발생 시 자동으로 배정됩니다.

**Q. 예약 시간에 늦을 것 같아요.**
A. 예약 시간 10분 이내 미방문 시 노쇼로 기록됩니다. 3회 누적 시 2주 이용 제한이 적용됩니다.

**Q. 출력이 완료됐는지 어떻게 알 수 있나요?**
A. 출력 완료 시 이메일 또는 문자로 알림이 발송됩니다. 반드시 확인 후 방문하세요. 48시간 내 미수령 시 폐기됩니다.

**Q. 대리로 출력물을 수령할 수 있나요?**
A. 불가합니다. 신청·출력·수령 모두 본인이 직접 해야 합니다.

**Q. 메일을 어떻게 써야 하나요?**
A. 공손한 표현으로 작성하고, 제목에 예약 날짜·시간·이름을 명시하고, 규칙에 맞는 파일명의 .gcode 파일을 첨부하세요.
