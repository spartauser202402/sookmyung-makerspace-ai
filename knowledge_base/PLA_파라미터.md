# PLA 출력 파라미터 사전

> 숙명 메이커스페이스 | 필라멘트: PLA 단일 고정 | 장비: 3DWOX1

---

## 0. 필라멘트 종류 안내 (초보자 필독)

3D 프린터에서 사용하는 재료를 **필라멘트(Filament)**라고 합니다. 필라멘트는 여러 종류가 있으며, 종류마다 출력 온도·특성·용도가 다릅니다.

### 주요 필라멘트 종류

| 종류 | 특징 | 난이도 |
|---|---|---|
| **PLA** | 가장 일반적. 냄새 적고 뒤틀림 적어 초보자 친화적. 생분해성. | ⭐ 쉬움 |
| **ABS** | 내열성·내충격성 강함. 출력 시 냄새 발생, 뒤틀림(워핑) 주의. | ⭐⭐⭐ 어려움 |
| **PETG** | PLA의 편의성 + ABS의 내구성. 투명/반투명 출력 가능. | ⭐⭐ 보통 |
| **TPU** | 고무처럼 유연한 소재. 휘거나 충격 흡수 필요한 부품에 사용. | ⭐⭐⭐ 어려움 |
| **Resin** | 광경화 수지. FDM(필라멘트) 방식이 아닌 SLA/DLP 방식에 사용. | 별도 장비 필요 |

### 숙명창작소에서 사용 가능한 필라멘트

> ✅ **PLA만 사용 가능합니다.**

숙명창작소 3DWOX1 프린터는 **PLA 소재만 지원**합니다.
ABS, PETG, TPU 등 다른 필라멘트는 사용할 수 없습니다.
반드시 **3DWOX1 정품 PLA 필라멘트와 스마트칩**을 지참하여 방문하세요.

## 1. PLA 소재 특성

| 항목 | 내용 |
|---|---|
| 재질 | 폴리락트산 (Polylactic Acid) — 생분해성 열가소성 수지 |
| 출력 온도 | 190~220°C (권장: 200°C) [확인 필요: 장비별 최적값] |
| 베드 온도 | 20~60°C (3DWOX1 기본값 사용 권장) [확인 필요] |
| 장점 | 냄새 적음, 뒤틀림 적음, 초보자 친화적 |
| 단점 | 고온 환경(60°C 이상)에 취약, 습기에 민감 |
| 주요 용도 | 프로토타입, 소품, 모형, 조형물 |

---

## 3. 오버행(돌출부) 처리 가이드

- **45도 미만 오버행**: 서포트 없이 출력 가능 (일반적)
- **45도 이상 오버행**: 서포트 활성화 권장
- 서포트 제거 시 표면이 거칠 수 있으므로 사포질 필요할 수 있음

---

## 4. 접착 문제 예방

| 방법 | 적용 상황 |
|---|---|
| 브림(Brim) 추가 | 바닥 면적이 작은 모델, 첫 레이어 접착 불안 |
| 래프트(Raft) 사용 | 베드 접착이 매우 어려운 경우 [확인 필요] |
| 출력 속도 감소 | 첫 레이어를 느리게 출력하면 접착 향상 |

---

## 5. 보관 주의사항

- PLA는 습기에 약하므로 사용 후 밀봉 보관 권장
- 습기를 흡수한 PLA는 출력 중 버블·스트링 현상 발생 가능
- 메이커스페이스 필라멘트는 담당자가 관리하므로 개인 반입 불가 [확인 필요]
