# 트러블슈팅 사례집

> 숙명 메이커스페이스 3D 프린터 (3DWOX1 / PLA) 출력 문제 해결 가이드

---

## 1. 워핑 (Warping) — 출력물 바닥이 들뜸

**증상:** 출력 중 모델 하단 모서리가 베드에서 떨어지며 휘어짐.

**원인:**
- 베드 온도가 너무 낮음
- 첫 레이어 출력 속도가 너무 빠름
- 모델 하단 면적이 좁음
- 주변 온도가 낮거나 바람이 들어옴 (특히 에어컨 근처)

**해결책:**
1. 브림(Brim)을 활성화하여 재슬라이싱합니다.
2. 베드 온도를 55~60°C로 설정합니다 [확인 필요: 3DWOX1 최적값].
3. 첫 레이어 속도를 20~30 mm/s로 낮춥니다.
4. 모델 위치를 베드 중앙으로 이동합니다.
5. 주변 바람/에어컨을 차단합니다.

---

## 2. 스트링 (Stringing) — 실 늘어짐

**증상:** 모델 사이에 얇은 실 같은 플라스틱이 걸쳐짐.

**원인:**
- 리트렉션(Retraction) 설정 부족
- 출력 온도가 너무 높음
- 이동 속도가 느림

**해결책:**
1. 3DWOX1 슬라이서에서 리트렉션 활성화 여부를 확인합니다.
2. 출력 온도를 5°C 낮춥니다 (예: 210°C → 205°C).
3. 이동 속도(Travel Speed)를 높입니다 [확인 필요: 3DWOX1 UI 경로].
4. 출력 완료 후 뜨거울 때 핀셋으로 조심스럽게 제거 가능.

---

## 3. 층 분리 (Layer Delamination) — 레이어가 벌어짐

**증상:** 출력 중 또는 후에 레이어가 갈라지거나 분리됨.

**원인:**
- 출력 온도가 너무 낮아 레이어 간 접착 불량
- 출력 속도가 너무 빠름
- 필라멘트 습기 흡수

**해결책:**
1. 출력 온도를 5°C 높입니다 (예: 200°C → 205°C).
2. 출력 속도를 10~15 mm/s 낮춥니다.
3. 필라멘트 상태 확인 (메이커스페이스 담당자 문의).

---

## 4. 노즐 막힘 (Clog) — 필라멘트가 나오지 않음

**증상:** 출력이 갑자기 멈추거나, 필라멘트가 나오지 않음.

**원인:**
- 이물질 혼입
- 오래된 PLA 사용
- 과도하게 높은 온도로 탄화

**해결책:**
1. 출력을 중지합니다.
2. **담당자에게 즉시 문의**합니다 — 사용자가 직접 노즐을 제거하면 안 됩니다.
3. 담당자가 콜드 풀(Cold Pull) 또는 노즐 교체를 진행합니다.

> ⚠ 노즐 막힘은 반드시 담당자에게 보고하고 직접 해결을 시도하지 마세요.

---

## 5. 첫 레이어 접착 불량

**증상:** 출력 시작 직후 모델이 베드에 붙지 않고 떨어짐.

**원인:**
- 베드 레벨링 불일치
- 베드 표면 오염 (기름, 먼지)
- 첫 레이어 높이 설정 오류

**해결책:**
1. 담당자에게 베드 레벨링 재조정을 요청합니다 [확인 필요: 3DWOX1 자동 레벨링 여부].
2. 베드 표면을 IPA(이소프로필 알코올)로 닦아 달라고 요청합니다.
3. 슬라이서에서 첫 레이어 높이를 약간 낮춥니다.
4. 브림을 추가합니다.

---

## 6. 서포트 제거 어려움

**증상:** 출력 완료 후 서포트가 모델에 강하게 붙어 제거가 힘듦.

**원인:**
- 서포트 Z 거리 설정이 너무 작음
- 출력 온도가 높아 서포트와 모델이 융합

**해결책:**
1. 가능하면 모델 방향을 바꿔 서포트를 최소화하도록 재슬라이싱합니다.
2. 뜨거울 때 핀셋과 니퍼로 조심스럽게 제거합니다.
3. 차갑게 식힌 후 비틀어서 제거하면 쉬울 수 있습니다.

---

## 7. 출력물 표면이 거칠거나 울퉁불퉁

**증상:** 완성된 모델 표면이 고르지 않음.

**원인:**
- 레이어 높이가 너무 큼
- 출력 속도가 너무 빠름

**해결책:**
1. 레이어 높이를 0.15 mm 이하로 낮춥니다 (최소 0.08 mm).
2. 출력 속도를 40 mm/s 이하로 낮춥니다.
3. 출력 완료 후 사포질(400번 → 800번 → 1200번)로 매끄럽게 다듬을 수 있습니다.
